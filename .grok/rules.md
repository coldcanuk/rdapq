# RDAP-Q Protocol for xAI Grok

When executing `/rdapq` commands or tackling complex engineering tasks:
1. Load `rdap-q-skill/SKILL.md` and `manifest.json`.
2. Apply evidence-first discipline: verify code, tests, and APIs before inferring facts.
3. Track task state in `.rdapq/state/`.
4. Score quality on the 0–10 calibrated scale; never falsify or inflate scores.
5. Obey diminishing-return exit gates.
